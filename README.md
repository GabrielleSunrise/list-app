# 🛒 Список покупок (Shopping List)

Простое и быстрое нативное Android-приложение для ведения списка покупок со встроенным пользовательским словарём продуктов и умным поиском.

## ✨ Основные возможности

* **Умный поиск и подсказки:** При вводе названия товара приложение мгновенно ищет совпадения в локальном словаре.
* **Гибкое добавление:** Незнакомый продукт можно добавить либо сразу **в список и в словарь**, либо **только в текущий список** (для разовых покупок). Первая буква автоматически становится заглавной.
* **Управление словарём:** Отдельное окно для просмотра всех сохранённых продуктов (с сортировкой по алфавиту), добавления новых позиций и удаления лишних.
* **Локальное хранение данных:** Список покупок и словарь сохраняются в памяти устройства (`SharedPreferences` + `Gson`) и не пропадают после закрытия приложения.
* **Удобная работа со списком:** Отметка купленных товаров (зачёркивание), удаление отдельных пунктов и быстрая очистка всего списка одной кнопкой.
* **Адаптивная тема:** Поддержка светлой и тёмной системных тем с кастомной цветовой схемой.

## 🛠 Стек технологий

* **Язык:** Kotlin
* **UI:** Jetpack Compose (Material 3)
* **Хранение данных:** SharedPreferences + Gson
* **Минимальная версия Android:** Android 7.0 (API 24)

## 🚀 Сборка и запуск

1. Клонируйте репозиторий:
2. Откройте проект в **Android Studio**.
3. Дождитесь синхронизации Gradle и запустите проект на устройстве или эмуляторе (`Shift + F10`).
4. Для сборки установочного файла выберите в меню: **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.
